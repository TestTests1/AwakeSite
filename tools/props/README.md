# Модели заграждений

`convert_barricades.py` достаёт модели заграждений из ассетов STALCRAFT и
складывает готовые `.glb` — те, что лежат в `frontend/awake-web/public/props/`
и расставляются игроками во вкладке «Мир».

## Зависимости

**scfile** — сторонний пакет с PyPI (проверено на 5.2.0), умеет читать игровые
форматы `.mcsb` и `.ol`. Это обычная зависимость, а не часть проекта:

```
pip install scfile
```

Плюс установленная игра: пути к ней заданы в начале скрипта константой `GAME`.

## Запуск

```
python convert_barricades.py <папка-назначения>
```

Скрипт перебирает список кандидатов и печатает по каждому размер или причину
отказа. В проект отобраны четыре: `barrikada`, `barikada_army`,
`barikada_army_2` и `gabionfull_1` — их названия сверены со строками
`go.clan.tournament_*` из `ru.lang` игры, а габариты подтверждают соответствие.
Остальные конвертируются, но не используются; список оставлен целиком, чтобы не
искать пути к файлам заново.

Связки «объект в игре → файл модели» в ассетах в открытом виде нет, поэтому
соответствие подтверждалось глазами во вьюере.

Текстуры лежат отдельными файлами `.ol` и в модели не входят — заграждения
рисуются заливкой цветом, для расстановки важны форма и габариты.
