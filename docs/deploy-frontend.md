# Развёртывание сайта

Фронтенд — статика. `npm run build` в `frontend/awake-web` даёт готовые файлы в
`dist`, сервер им не нужен. В контейнер API он не входит: `Dockerfile` собирает
только `src/Awake.API`, а папка `frontend` исключена в `.dockerignore`.

## Где размещать

Разумнее всего **Cloudflare Pages**: домен и модели локаций уже там, раздача
статики бесплатна и без платы за трафик, сборка цепляется к репозиторию и
обновляется на каждый пуш.

Настройки сборки:

| поле | значение |
|---|---|
| корень проекта | `frontend/awake-web` |
| команда сборки | `npm run build` |
| каталог вывода | `dist` |

Второй сервис в Railway тоже сработает, но это лишний контейнер и платный
трафик за то, что Cloudflare отдаёт даром.

## Переменные сборки

```
VITE_API_URL=https://api.stalcraftclans.cc
```

**Это переменные времени сборки, а не запуска.** Vite вшивает их в бандл;
поменять после сборки нельзя, надо пересобирать. На `VITE_API_URL` завязаны
обычные запросы и оба хаба — уведомления и мир.

## Модели фигуры и заграждений

Модель игрока и четыре заграждения весят вместе около 940 КБ и лежат в
`public/avatars` и `public/props`. Они **исключены из репозитория** вместе с
остальными игровыми ассетами, поэтому сборка из чистого клона соберёт сайт без
фигуры игрока и без баррикад — молча, просто ничего не появится.

Варианта два.

**Выложить рядом с картами** в то же хранилище и задать при сборке:

```
VITE_ASSETS_URL=https://models.stalcraftclans.cc
```

Тогда модели поедут с `https://models.stalcraftclans.cc/avatars/v1.glb` и
`/props/*.glb`. Заливка — как у карт, `wrangler r2 object put … --remote`, не
забыв `--content-type model/gltf-binary`. Репозиторий при этом остаётся без
игровых ассетов, что для публичного репозитория существенно.

**Либо вернуть их в репозиторий**, убрав соответствующие строки из `.gitignore`.
Проще, но 940 КБ ассетов, вынутых из чужих игр, окажутся в открытом доступе.

Без `VITE_ASSETS_URL` файлы берутся из самой раздачи сайта — так работает стенд.

## Маршрутизация

В `public/_redirects` лежит правило `/* /index.html 200`. Оно обязательно:
маршрутизация у нас клиентская, файла `/world` на диске не существует, и без
правила прямой заход по ссылке или перезагрузка страницы вернут 404. Vite
копирует `public` в `dist`, так что файл попадает в сборку сам.

## Домен

Корень `stalcraftclans.cc` направляется на Pages. API живёт на отдельном
поддомене — см. `deploy-railway.md`.

После смены домена проверьте, что на стороне API заданы
`Cors__AllowedOrigin=https://stalcraftclans.cc` и адрес возврата Discord.
