# Раздача моделей локаций

Три модели весят вместе около 580 МБ, и каждый просмотр карты — это 145–256 МБ
на игрока. Держать их внутри образа приложения дорого: они раздувают сборку и
деплой, а трафик идёт через тот же хостинг, что и API. Поэтому источник моделей
переключается настройкой.

## Как это работает

Эндпоинт `GET /api/maps/{location}/model` закрыт рангом Member и ведёт себя
по-разному в зависимости от `MapAssets:BaseUrl`:

- **пусто** — модель отдаётся с диска из папки `MapAssets` рядом с приложением.
  Так работает стенд разработки.
- **задан адрес** — эндпоинт отвечает перенаправлением на
  `{BaseUrl}/{локация}.glb`, и клиент забирает файл из хранилища напрямую.

Имя файла берётся из белого списка локаций, а не из запроса, поэтому подставлять
его в адрес безопасно.

Проверка ранга остаётся в обоих случаях: адрес в хранилище узнаёт только тот, кого
пустили. Стоит понимать границу — сам адрес после этого ничем не защищён, и
получивший его может передать дальше. Для геометрии игровых локаций это разумный
размен; если понадобится настоящая защита, вместо постоянного адреса нужно будет
выдавать подписанную ссылку с ограниченным сроком, и менять придётся только
`MapAssetService`.

## Кеширование

При раздаче с диска ответ несёт `ETag` и `Cache-Control: private, max-age=86400`.
Признак версии считается из размера и времени правки файла — считать хеш от
сотен мегабайт на каждый запрос дороже самой отдачи. Повторный заход отдаёт
`304 Not Modified` без тела, то есть модель качается один раз.

Кеш приватный намеренно: эндпоинт закрыт рангом, и общим прокси складывать ответ
у себя нельзя.

В хранилище то же самое настраивается на стороне бакета. Модели неизменяемы,
поэтому имеет смысл `Cache-Control: public, max-age=31536000, immutable`, а новую
версию выкладывать под новым путём — например `/maps/v2/`, — и менять `BaseUrl`.

## Что нужно от хранилища

1. **Публичное чтение** файлов `hvoiny.glb`, `small_berdovka.glb`, `nizina.glb`.
2. **CORS**: разрешить `GET` с домена сайта. Фронтенд читает ответ потоком, чтобы
   показывать ход загрузки, поэтому обычного `Access-Control-Allow-Origin`
   достаточно, но он обязателен — без него браузер не отдаст тело скрипту.
3. Желательно **поддержка Range-запросов**, чтобы обрыв не начинал загрузку с
   нуля. У S3-совместимых хранилищ она есть по умолчанию.

Запрос модели уходит с `credentials: 'omit'` именно поэтому: браузер разрешает
запрос с учётными данными на чужой домен только если тот вернёт точный
`Access-Control-Allow-Origin`, а публичные хранилища отдают `*`. Токен передаётся
заголовком и от этого режима не зависит.

## Настройка

```
MapAssets__BaseUrl=https://<хранилище>/maps/v1
```

Переменной окружения достаточно, отдельного секрета не нужно — адрес не
конфиденциален.

## Развёртывание на Cloudflare R2

Развёрнуто: бакет `awake-maps`, домен `models.stalcraftclans.cc`, путь `maps/v1/`.

```
wrangler login
wrangler r2 bucket create awake-maps
wrangler r2 bucket cors set awake-maps --file infra/r2-cors.json
wrangler r2 bucket domain add awake-maps \
  --domain models.stalcraftclans.cc --zone-id <ZONE_ID> --min-tls 1.2

wrangler r2 object put awake-maps/maps/v1/nizina.glb \
  --file src/Awake.API/MapAssets/nizina.glb \
  --content-type model/gltf-binary \
  --cache-control "public, max-age=31536000, immutable" \
  --remote
```

Последняя команда повторяется для `hvoiny.glb` и `small_berdovka.glb`.

**`--remote` обязателен.** Без него wrangler пишет в локальную симуляцию хранилища
и бодро сообщает «Upload complete» — файл при этом никуда не уезжает, а на диске
остаётся папка `.wrangler` весом с саму модель. Признак подмены один: в первой
строке вывода `Resource location: local`.

Идентификатор зоны виден в панели Cloudflare на странице домена. Сертификат для
поддомена выпускается пару минут; готовность видно в
`wrangler r2 bucket domain list awake-maps` — оба статуса должны стать `active`.

**Свой домен обязателен.** Публичный адрес вида `r2.dev` намеренно ограничен по
скорости и полосе и при нагрузке отвечает `429` — Cloudflare прямо пишет, что он
только для разработки. Для файлов в сотни мегабайт это не годится. Зона домена
должна быть в том же аккаунте, что и бакет.

Если после настройки браузер всё равно ругается на CORS, сначала посмотрите
заголовки ответа: `cf-mitigated` означает, что запрос отклонило правило WAF, а
отсутствие `cf-cache-status` — что сработала защита от хотлинка. Это не CORS, и
чинится в других настройках.

### Кеш на границе сети

Сейчас ответы приходят с `cf-cache-status: DYNAMIC`, то есть Cloudflare их у себя
не складывает: по умолчанию кешируются только определённые расширения, и `.glb` в
их число не входит. На корректность и на счёт это не влияет — исходящий трафик из
R2 бесплатен, — но каждый запрос идёт до хранилища. Если захочется отдавать
модели с ближайшего узла, нужно правило кеширования «Cache Everything» на
`models.stalcraftclans.cc`. Тогда же имеет смысл включить Smart Tiered Cache.

Если адрес не задан и моделей на диске нет, приложение при старте пишет об этом
предупреждение: иначе ошибка всплыла бы только у игрока в виде пустой вкладки.

## Откуда берутся файлы

Собираются конвейером из `tools/maps` — см. README там же. В git модели не
входят: у GitHub жёсткий предел 100 МБ на файл, а каждый пере-экспорт добавлял бы
в историю новую полную копию.
